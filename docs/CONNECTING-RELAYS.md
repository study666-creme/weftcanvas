# 连接中转站

画布支持浏览器自带 Key（BYOK）直连。模型请求从浏览器发送到你选择的中转站；
本地项目无需数据库、服务端计费或生成 worker。

## 首次接入

1. 设置 → API 配置 → 添加配置。
2. 填入中转站提供的服务地址与 API Key，选择 OpenAI 兼容或 Gemini 原生协议。
3. 点击「拉取模型」，确认返回的模型列表与该 Key 的权限一致。
4. 在节点生成面板选择模型，检查参数后发起生成。

OpenAI 兼容接入读取 `/v1/models`；Gemini 原生接入读取其 models 接口。
常见模型按官方 ID 识别，未识别的模型可手动标注模态。识别仅补充默认路由和参数，
不会验证你选择的渠道是否真的支持该模型。

## 协议差异

同一个模型在不同中转站可能有不同的接口。高级协议面板支持：

- Bearer、自定义请求头或查询参数认证。
- 各模态提交端点，以及 JSON、表单或 multipart 请求体。
- 异步任务 ID、轮询地址、状态码、进度与结果路径。
- 错误消息和错误码的点路径提取。

例如，上游返回 `{"data":{"id":42,"state":2,"url":"https://cdn.example/video.mp4"}}`，
可配置任务 ID 为 `data.id`、状态为 `data.state`、成功值为 `2`、结果路径为 `data.url`。
数字与字符串状态码均可读取；未知状态不会被猜成成功。

「解析自检」只处理粘贴的响应 JSON，不联网、不计费。「测试请求」会向所选文本模型
发送真实请求，可能计费；它不证明图片、视频或音频模型可用。

## 常见问题

| 现象                   | 检查项                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 模型列表拉取失败       | 先看地址与网络是否可达，再查 Key 权限与上游 CORS（预检要放行 OPTIONS 与认证头）；浏览器 Network 面板里被拦的请求会直接写明原因 |
| 服务地址被拒绝         | 只接受 HTTPS，或本机与局域网地址的 HTTP（127.0.0.1／localhost、192.168.x／10.x／172.16-31.x、`*.local`、`nas` 这类短主机名）   |
| 能拉列表，但生成失败   | 当前渠道是否可用、提交端点、请求体参数、模型 ID                                                                                |
| 视频一直等待           | 任务 ID、轮询地址、成功/失败状态值、结果路径；先用真实响应做解析自检                                                           |
| 模型没有出现在生成面板 | 模态标注、模型显示选择、配置启用状态                                                                                           |
| 结果链接加载失败       | 链接过期、CDN 跨域策略、浏览器访问权限                                                                                         |

HTTPS 页面不能调用 HTTP 中转站（浏览器的混合内容限制，`http://127.0.0.1` 除外）。
局域网自用可以直接走 HTTP：本机与私网地址都算可信，画布页面本身用 HTTP 打开即可
直连。中转站应允许画布来源的 CORS 请求，包括认证头、提交和轮询接口，以及需要
下载的结果资源。Key 保存在当前浏览器的 localStorage 中，请使用受信任的画布部署。

## 模型列表跟随

画布按目录新鲜度窗口重新拉取，显示新增与下架的模型。更新频率受画布刷新和
中转站自己的目录同步频率影响。它不自动解决新协议、渠道故障、权限或 CORS 差异。

需要精确参数、价格和渠道可用性时，可以发布 [合同目录](UPSTREAM-CONTRACT.md)。
只读导出脚本能提供初始结构，缺失的价格和协议必须由站长确认。验收探针复用 API
目录校验，只证明目录结构可接入；各模态的实际执行仍需单独验证。

## 反馈接入问题

提交 GitHub issue 时提供中转站软件及版本、模型 ID、协议类型、复现步骤、HTTP 状态码
和脱敏响应。不要提交 API Key、管理 token、签名下载链接或含凭据的完整配置。
