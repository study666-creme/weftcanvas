# 插件（用户向）

纬线的插件用来**扩展画布本身**——最典型的用途是新增一种节点类型。
本页只讲「作为用户，插件从哪来、怎么装、怎么停」。开发者向的写法见
[`../plugins/README.md`](../plugins/README.md) 与
[`../packages/plugin-sdk/README.md`](../packages/plugin-sdk/README.md)。

## 在哪管理

打开画布 → 右上角「设置」→「插件」板块。这里能看到每一个官方插件的当前状态，
并按状态给出对应操作：

- **装载**：把随应用打包、但当前没启用的官方插件装回来（它的节点会重新出现在创建菜单）。
- **停用**：暂时收起这个插件，回收它注册的节点类型；画布上**已存在**的该类型节点仍照常渲染，
  随时可一键「启用」恢复。
- **卸载**：彻底移除，效果同停用，但在列表里显示为「可重新装载」。

装载 / 停用 / 卸载的选择会**记住**（存在本浏览器），刷新页面、下次打开都不会被自动改回去。

## 插件从哪来

**目前只有官方插件**——即随应用一起打包、由纬线维护的那几个（现在示例是「批量拆单」
`split-list`：把多行文本拆成一串相连的文本节点）。它们不需要你去找、去下载，
在上面的「插件」板块里直接装载即可。

**第三方插件的在线获取与安装正在规划中。** 现阶段画布不加载任何来自 URL 的远程代码，
也不执行粘贴进来的脚本——这是刻意的安全边界：插件不接触模型密钥，来源随应用构建固定。
等信任模型（来源校验、权限明示）就绪后，才会开放「从外部安装」。

想自己写一个？用 `@weftcanvas/plugin-sdk` 的 `definePlugin`，把一个节点类型注册进去即可，
详见仓库 `plugins/README.md`。在官方开放在线安装之前，自写插件通过本地开发入口装载。

## 卸载会怎样

卸载 / 停用会回收插件注册的节点类型：它们从「添加节点」菜单里消失，不再能新建。
但**已经画在画布上的节点不会被删除、也仍然渲染**——只是暂时不能由这个插件管理。
重新装载后一切恢复。
