## 填写说明（签署前删除本节）

1. **授权版本务必双写**：tag 可以被人为移动，commit 不会。授权书里写「tag vX.Y.Z（commit 完整 sha）」最稳。公开仓库每次发布都会打 tag（见仓库的 Tags 页），取当时的 tag 与它指向的 commit 填进附件一。
2. **年度 vs 永久的差别只有两点**：覆盖版本（年度含授权期内发布的版本、永久只含列明版本）与期限（是否续费）。价格区间见 `COMMERCIAL-LICENSE.md`。
3. **「1 个产品 / 服务」要认真填**：这是最常见的争议点。多产品、多主体、要给客户做 OEM 的，一律走 OEM 方案单独签。
4. **不包含实施与支持**：部署、定制、迁移、SLA 都是另行计价项，别口头承诺；要卖就写进附件一。
5. **AGPL 与商业授权的关系**：不买授权也能用（AGPL 允许商用），只是被要求公开（修改过的）源码；商业授权的价值就是「闭源豁免」。因此不要对纯 AGPL 用户主张「必须先买授权」。
6. **付款与开票先谈清**：个人 vs 企业主体、能否开专票、付款账期，往往决定第一单能不能成。
